Write a video script for a client's social media or ad campaign.

Ask the user for the following if not already provided:
- Business name, industry, and brand tone
- Target audience
- Video type: organic short-form (Reels/TikTok/Shorts), paid ad, testimonial, explainer, or promo
- Platform: Instagram Reels, Facebook, YouTube, TikTok, or YouTube Shorts
- Video length: 15s, 30s, 60s, or 90s
- Primary message or offer
- Call to action
- Words to always use / never use
- Any visuals, locations, or people involved (if known)

Then write the script following these rules:
- Reflect Christian values — honest, encouraging, never manipulative
- Hook in the first 3 seconds — must stop the scroll
- Structure: Hook → Problem or Context → Solution → Proof or Benefit → CTA
- Write spoken dialogue naturally — how a real person talks, not how they write
- Include on-screen text cues (if short-form) and shot direction notes
- Keep pacing tight — 2–3 words per second for spoken content
- CTA must be clear, direct, and low-pressure

Output format:
- Scene-by-scene breakdown with: timecode, on-screen text, voiceover/dialogue, shot direction
- Total estimated word count and read time
- Optional: B-roll suggestions or music mood note
