Generate social media captions for a client's content calendar.

Ask the user for the following if not already provided:
- Business name
- Brand tone and target audience
- Content pillars (up to 3)
- Platform (Facebook, Instagram, or both)
- Number of posts needed
- Month and any current promotions or seasonal focus
- Words to always use / never use

Then generate captions following these rules:
- No more than 20% of posts should be directly promotional
- Vary formats across: Tip, Question, Behind-the-Scenes, Storytelling, Promotional, Testimonial
- Instagram: punchy opener in first 138 characters; include 5–10 hashtags
- Facebook: conversational tone; no hashtags
- Include an image concept for every post (1–2 sentences for Canva AI or a designer)
- Distribute posts evenly across content pillars
- Use the prompt structure in /templates/social-caption-prompt.md

Output as a numbered list with: post date suggestion, platform, pillar, format, caption, hashtags (Instagram only), and image concept.
