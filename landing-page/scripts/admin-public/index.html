How the Daily Scheduler Works

Run node scripts/blog-scheduler.js in the background (or via the start-all.bat) to enable daily posting. It runs every day at 6am, 10am, 2pm, and 6pm — skipping Saturday. It pulls the next topic from the queue, calls blog-writer.js, and publishes automatically.
