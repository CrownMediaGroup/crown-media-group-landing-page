2

Get your paper-trading API key

From the Alpaca dashboard:

  • Switch the toggle at the top from "Live" to "Paper"
  • Click your profile → API Keys
  • Click Generate New Key
  • Copy the Key ID AND the Secret Key (the secret only shows once — save it now)
3

Paste them below

We'll encrypt them on the server using AES-256 and call Alpaca to confirm the keys work.
